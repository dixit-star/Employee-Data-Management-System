#  Employee Data Management System

Employee Data Management System is a web-based application built using **HTML, CSS, and JavaScript**.  
The project allows users to manage employee records efficiently by adding, viewing, updating, and deleting employee data through a clean and interactive user interface.

This project focuses on strengthening **JavaScript fundamentals**, **DOM manipulation**, and **CRUD operations** without using any framework.

---

##  Live Demo
🔗 https://employ-data-management.netlify.app

---

##  Features

-  **Add Employee Details**
  - Add employee information such as name, ID, role, and salary
  - Form validation using JavaScript

-  **Display Employee Records**
  - Employee data displayed dynamically in a table
  - Real-time UI updates without page reload

-  **Update Employee Data**
  - Edit existing employee details
  - Changes reflect instantly in the UI

-  **Delete Employee Records**
  - Remove employee data from the system
  - Smooth and instant DOM updates

-  **LocalStorage Support**
  - Employee data is stored in browser LocalStorage
  - Data remains even after page refresh

-  **Responsive Design**
  - Works smoothly on mobile, tablet, and desktop devices

-  **Clean & User-Friendly Interface**
  - Simple layout for easy data management
  - Beginner-friendly UI

-  **Fast Performance**
  - Built using pure HTML, CSS, and JavaScript
  - No external libraries or frameworks used

---

##  Tech Stack

- **HTML5** – Structure of the application  
- **CSS3** – Styling and responsive layout  
- **JavaScript (ES6)** – Logic, DOM manipulation, and LocalStorage
